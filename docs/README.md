# Mandate docs

Mintlify source for the public docs site. Preview locally:

```bash
cd docs
mint dev
```

Scriptorium slots live in `images/`:

- `hero-slot.svg` for the README hero
- `leash-line-slot.svg` for a themed Leash Line
- `video-theme-slot.svg` for a video still
- `docs-art-slot.svg` for docs art direction

`leash-line.png` is a real terminal capture from `demo/run_demo.sh`, not a placeholder. When the themed assets land under `/workspace/scriptorium/hackathon-desk/2026-11-10/mandate/`, replace the slot files (and optionally the hero) in a follow-up change. Do not add Nous logos.
