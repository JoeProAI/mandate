# Mandate docs

Mintlify source for the public docs site. Preview locally:

```bash
cd docs
mint dev
```

Night Yard images live in `images/`. The themed plates (hero, section art, Leash Line, logos, favicon, and thumb-bg) replace the old slot SVGs. `leash-line.png` is still a real terminal capture from `demo/run_demo.sh`. There are no Nous logos.
